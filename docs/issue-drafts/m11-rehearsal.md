# M11 展示彩排与故障备用

负责人 @shenzeyu070918-eng。截止时间待确定。

## 目标

按现场设备和投影条件完成一次从启动到分析报告的彩排，验证每个备用入口能单独打开。使用合成或明确可展示的材料。

## 验收清单

- [ ] 验证 Mac 内屏及投影镜像与扩展，检查大屏后排能读清关键结论和状态提示。
- [ ] 从启动脚本完整走一遍摄像头启动、九点校准、练习和眼手星系。核对退出、暂停和热键，并记录各步骤实测用时和失败原因。
- [ ] 用演示海报和手动 AOI 模板跑一遍刺激物报告，核对离线 HTML、PDF 和逐次确认的 AI 解读。
- [ ] 模拟摄像头不可用、WebGL 失败和断网。分别验证无需摄像头的星系预览、适用时的 Qt 备用、预生成的合成报告与 PDF。
- [ ] 用发布源码包核对启动入口。复核备用材料和公开链接不含个人录制、摄像头画面或密钥。
- [ ] 在验证记录中记下设备、版本、成功与失败、实测耗时及现场切换顺序。

涉及文件为展示操作清单、使用手册与验证记录。产品修复按彩排结果另列。

背景见 [M10 PR #17](https://github.com/shenzeyu070918-eng/monocular-gaze-mvp/pull/17) 与[验证记录](https://github.com/shenzeyu070918-eng/monocular-gaze-mvp/blob/main/验证记录.md)。
