# M10 预注册验收（2026-11-03，产品代码实施前锁定）

范围：读取M9屏幕/刺激物会话，生成离线统计报告、刺激物多人汇总、可选且逐次确认的AI解读。经验精度约1.3–2.5cm、四轮硬归属66.7%–85.3%，只做块级结论。该范围不改变M9验收、归属算法、校准档案或原始录制。

## 固定门槛

1. **30秒会话结束至统计报告打开≤60秒**：起点为用户请求结束的单调时钟，包含M9整理/OCR和报告生成；终点为浏览器完整显示报告。另记HTML就绪、发起打开请求，不把openUrl返回成功冒充首屏呈现。屏幕及刺激物各用一份预先固定的30秒样例；不跳过失败场景/OCR、不删数据追认通过。未实测保持未验证。
2. **断网完整生成统计报告**：HTML图片/字体替代/样式/脚本均本地，双击可读。无AI配置、失败或断网也必须有统计报告及明确原因。
3. **未确认零发送**：确认前不得向provider发送HTTP/DNS或模型探测请求；取消、取消场景、配置/内容改变、重试均受确认门控。报告本身无远程资源或密钥。自动测试仅用模拟provider/transport，禁止访问外网。
4. **API key不出现在任何输出**：只读取环境变量或macOS钥匙串。用哨兵密钥扫描HTML、JSON、PDF、日志和异常；不记录请求头或完整错误响应，测试也覆盖provider恶意回显密钥。
5. **多人汇总在合成数据上正确**：按刺激物SHA256和匿名参与者编号去重；重复编号不可凑人数，旧会话须事后映射。统一AOI模板、每人等权、未看者首次时间为空、人数及各分母清楚；N=1不得使用群体结论。
6. **AI输出数字与统计一致**：本地证据引用表核对metric_id、数值、单位、人数及所选场景；错误、缺证和不合法JSON均降级，不自动再发。中文输出，面向设计者建议，禁止逐字逐行或从单人泛化。
7. **单张刺激物AI确认发送至报告更新≤30秒**：包含网络、结构化校验、报告写完/更新，等待显示进度；总预算超时降级至统计报告并说明原因，不用只计HTTP的办法缩短口径。真实服务表现以实测为准，不以模拟provider耗时冒充达标。

## 统计定义及数据完整性

- 有效注视覆盖率为有效且已绑定注视时长/会话墙钟时长；背景/屏外/眨眼/无脸/暂停/断档/不确定区间保留，不通过改变分母提高结果。
- AOI硬软时长/占比并列。首次注视、进入次数、顺序使用硬归属；软归属为连续概率质量，不伪造离散进入。未记录有效注视不等于确定未看或未理解。
- 关键结论卡片3–5项，数字全部来自本地统计。scanpath仅为显示，可截前N或合并连续邻近点，不改统计；圆面积与停留时长成比例，跨排除/场景/暂停不连线，多人不画路径。
- 新刺激物会话开头输入可修改的匿名编号，默认P01/P02递增并写入session.json。多人N按唯一参与者计，不按会话计；同一人同一图片的重复记录需明确选一次。
- 旧会话/离线恢复结果只读，报告带数据版本、来源和异常提示；原始文件和M9判定不覆写。精度半径沿用会话核尺度，来源示意值与实测核对须分清。

## 实机清单（结果未验证）

1. Mac断网录30秒屏幕会话，结束一键生成，计时到完整可读；核对场景/时间线、单文件移动后打开、一次PDF。
2. Mac断网录30秒刺激物，输入匿名编号，结束自动报告；检查投影首屏结论、scanpath、打印、AI确认取消/取消场景及进度。多人逻辑由合成测试覆盖，不强求真人多人。
3. 用户自愿选非敏感刺激物、确认后真实AI一次：记录确认至报告更新耗时、usage/核算费用、中文证据一致性；未做时记未验证。真实AI请求不属于自动测试。
