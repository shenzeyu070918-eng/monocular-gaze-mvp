# M10 报告使用与验证

预注册固定门槛见 [m10-acceptance.md](m10-acceptance.md)。M10 没有改 M9 的九点矩阵、注视检测、绑定与归属算法，也没有改 M9 正式验收记录。

## 一次使用

1. 用匹配的 Python 九点档案开启图片刺激物会话。开始前输入匿名编号，默认 P01、P02…；同一个人跨会话请改回同一编号，不填写姓名。编号写入 `session.json`。
2. 结束后后台完成 OCR/绑定，自动生成并打开统计报告。屏幕会话结束后点击面板「生成/打开注意力报告」。也可选择旧会话；有恢复版本时明确选择，不自动用“最新”掩盖原错误。
3. 首屏五项结论全部来自本地统计。场景图细框编号对应 AOI 表；路径图只用于显示，圆面积与停留时长成正比，暂停、排除及场景之间不连线。`report.scanpath_max_points`、`scanpath_merge_sigma`、`scanpath_gap_s` 仅影响路径图，不改统计。
4. HTML 自带图片和样式，可复制到另一位置、断网双击。PDF 可从面板导出（本地 Chrome 临时独立配置），或浏览器打印→另存为 PDF。没有 Chrome 不影响 HTML。
5. 已生成报告在 `data/attention/<id>/reports/<报告版本>/`：`report.html`、`data.json`、`manifest.json`，可选 `report.pdf`；成功 AI 增加 `ai.json`，失败有 `ai-status.json`。原会话、截图、核对和验收文件只读。删除整个会话会同时删除它下面的报告；另行复制的备份需自行删除。

只分析块级区域：经验精度约 1.3–2.5 cm，M9 四轮硬归属为 66.7%–85.3%。未记录注视不等于未看见、未理解；停留不代表偏好。截图热图显示的是同一场景中的区域，不跨滚动拼接内容。

报告在每个主 AOI 下列出显示宽高（厘米）和适用的自动合并原因。刺激物按图像在屏幕上的实际显示范围计算，缺少实测尺寸时显示「物理尺寸未记录」。多人汇总显示有实测数据者的尺寸范围。演示海报的标题、产品图、价格和按钮建议在 AOI 编辑器中手动框选，保存为按图片 SHA256 复用的模板。手动边界保留，低于误差尺度的区域仍会标明结论不可靠。

## 本地命令行

在项目根目录、已安装的环境中运行；这些命令不会请求 AI：

```sh
python tools/attention_report.py data/attention/<会话id> --open
python tools/attention_report.py data/attention/<会话id> --pdf
python tools/attention_report.py data/attention/<会话id> --derived derived/<恢复版本> --open
python tools/attention_report.py data/attention/<会话1> data/attention/<会话2> --aggregate --open
```

旧会话缺编号时，加 `--participant-map data/participants.json`，文件示例：`{"会话1":"P01","会话2":"P02"}`。映射不回写原文件。相同编号的重复会话直接拒绝，用户须明确选一次；不能把同一个人的多次录制凑成人数。刺激物原始图片 SHA256 必须相同。需要指定汇总 AOI 时用 `--aoi-template data/template.json`，格式沿用 M9 矩形列表。

面板「刺激物多人汇总」可逐个选择目录，旧会话会提示事后编号。默认使用首份会话的 AOI 作为统一模板，对每人已绑定注视重新调用 M9 `AOIStatistics`；不拿不同 OCR 的同名或序号直接相加。每人热图先按自身总热量归一化，再等权平均；无有效注视者不加入热图平均。

- `N_total`：唯一匿名参与者数；`N_valid`：有已绑定有效注视者数；`N_seen`：对该 AOI 有硬归属注视者数。
- 看过比例 = `N_seen / N_valid`，表中显示分子分母。无有效注视不算“没看”；均值分母明确。
- 首次注视时间仅对看过者求平均；无人看过为未知，不填 0。时长和占比为有效参与者逐人等权平均，不让更长的会话支配结果。
- 硬归属定义离散进入和首次；软归属是高斯概率质量，没有独立的“软进入次数”。背景和屏外概率保留在数值文件中。
- N=1 仅单人描述。汇总不画混杂个人的 scanpath；保留各人统计与核尺度供核查。

## 可选 AI：每次都先确认

统计报告和 CLI 完全不需要网络或密钥。AI 仅从运行中的控制面板「AI解读当前报告」进入；离线 HTML 没有联网能力，也不含密钥。备份报告双击即可看统计。

配置在 `report`，可用 `config/local.yaml` 覆盖。当前默认第一方DeepSeek：`provider: chat`、`base_url: https://api.deepseek.com`、正式图片模型`deepseek-flash`，默认关闭思考；不支持图片的模型自动纯文字。查证日期2026-11-06，模型、JSON、纯文字、当前单价与高峰/非高峰规则见 [DeepSeek接入说明](deepseek-provider.md)。

密钥只从默认环境变量 `DEEPSEEK_API_KEY` 或 Mac钥匙串通用密码项读取，服务/账户为 `monocular-gaze-report` / `deepseek`。不读取旧OpenAI密钥，不把密钥写入YAML、JSON、日志、命令参数或报告。
确认窗列出服务地址、模型、实际缩略图、完整请求字段及本地 token/费用预算，可取消个别场景。OCR JSON 默认关闭；**截图内的文字仍可能被读到**，请逐图检查。取消场景同时移除其图片、AOI及数值；不发送匿名编号、应用名、完整时间线或其它未选场景汇总。预算采用文本字节和显式图像预算的本地保守算法，不是官方精确计数，也不是费用保证。

确认绑定确切内容、地址、模型、单价和提示词版本，只能使用一次。改内容或重试需新确认，不自动探测模型、不自动重试、不跟随服务重定向。DeepSeek不传`store`；本项目不据此推定服务端存储策略。

AI 用中文给设计者建议。每条总结、发现、建议带 `metric_id/value/unit`，正文用证据占位符，由本地数字填入；拒绝数值、单位、人数或场景不一致、无引用、单人泛化和格式错误。小数、百分比和带计量单位的统计数字须使用证据占位符，已知整数计数和短标签可以原样使用。局限说明由本地生成。无效的发现或建议逐条移除，报告显示条数和原因，脱敏原文写入 `ai-rejected.json`。区域引用通过 ID 占位符显示为本地短标签。精度、历史硬归属范围和样本量使用固定说明占位符，当前场景统计仍须有独立证据。总结无效时改用本地统计摘要，发现和建议均无合格条目时才舍弃整份解读。它仍可能在语义上误读，不能替代设计者判断。报告记录模型、时间、提示词版本、数据版本、usage、价格快照及核算费用；usage、缓存明细或价格缺失时费用为未知，不能填零或冒充实际账单。

确认后显示等待秒数，总预算最多 30 秒，包含请求、校验和报告更新。网络独立进程使 DNS/TLS 卡住也能截止；超时、断网、无配置或校验失败保留统计报告及原因，无后台补发。原始服务响应不写盘，输出/错误的密钥回显会被移除。

## 面板操作反馈与会话选择

在「当前会话」下拉列表按本机时间、屏幕或刺激物模式、编号选中会话，再点「生成/打开注意力报告」。如仍在整理，面板显示等待状态，整理完成后为所选会话生成报告。AI 解读和 PDF 按钮作用于所选会话已生成的报告。进行中按钮置灰，状态在按钮旁显示，完成或失败时面板给出提示。导出的 PDF 通过系统默认查看器打开。

AI 失败会在面板与报告中显示分类。类别包括未读到密钥、密钥格式异常、证书或 TLS、DNS 或网络、超时、HTTP 401、402、400/422、429 和 5xx。DeepSeek 参数错误附脱敏后的服务端提示。报告保留已生成的统计和此前通过校验的解读。

## 最后一轮实机步骤

此前 Mac 屏幕报告打开用时 19.9 秒，刺激物自动打开用时 1.1 秒，PDF 导出和断网取消已通过。最终复核沿用 [M10 预注册](m10-acceptance.md)。

1. 切换到 `m10-report` 并重启悬浮层。断网各录一次约 30 秒的屏幕会话和刺激物会话，从结束计时到完整报告可读，门槛均为 ≤60 秒。核对标题显示图片文件名、单图副标题正确、主 AOI 默认不超过 12 个。复看 369de32f 的派生报告，核对小单元格合并结果；抽查一次 PDF 和确认窗取消。
2. 在「钥匙串访问」按 [DeepSeek 凭据步骤](deepseek-provider.md#在-macos-钥匙串保存-api-key)添加 key。恢复网络，先用非敏感合成海报打开确认窗，核对服务地址、模型、字段和费用估算。勾选纯文字时缩略图消失，再取消发送。
3. 如愿实测真实 AI，在同一非敏感报告明确确认一次发送。记录确认到报告更新耗时（≤30 秒）、模型、usage、估算费用以及中文建议的引用数字。超时应保留统计报告，真实结果如实记入验证记录。

Windows、真实 DeepSeek 调用与投影可读性仍待实机核验。

## 版式与实现边界

色板：背景 `#F2F7FC`、文字 `#102F50`、重点 `#215E93`、提示 `#D78220`、纸面 `#FFFFFF`、次级文字 `#4E657A`。中文使用本机苹方/微软雅黑等，不下载字体。左对齐、五个结论为主层次；投影标题48px、关键值42px、正文22px，表格18px；A4独立10.5pt打印样式。没有装饰动画。

`gaze_core/reporting`：只读数据适配、路径显示、汇总、HTML/PDF、证据白名单/确认/凭据/provider；`overlay/reporting.py`：原生预览、后台任务、轻量结果轮询；`tools/attention_report.py`：只离线。所有AI自动测试用模拟transport，不调用真实服务，不用真实模型耗时替代预注册实测。

## 2026-11-05 预审修正：层级 AOI 与本地编辑

当前自动AOI算法版本为 `hierarchical-v3`（包含下述v2层级及新增精度尺寸合并），AOI JSON schema为2。先用OpenCV识别矩形卡片、图片/色块容器，再把内部OCR文字归为 `role: child, ranked: false` 子区域；统计与排名只使用主区域，避免父子双计时。检测保留细边框，去重嵌套边缘；圆形产品零件不直接当矩形，宽主图内少量小矩形也不会把主图误当页面包装层。容器外文字按列合并，过滤纯符号、过短、低置信度和过小OCR结果。参数均在 `attention.aoi_*`。

旧平面AOI报告会用原截图、缓存OCR和已绑定注视只读重建，并在报告中标注 `hierarchical-v3/report-view`；不改原会话。要落一套可检查的完整派生AOI/统计/热图版本，运行：

```sh
python tools/attention_session.py data/attention/<会话id> --rebind
python tools/attention_report.py data/attention/<会话id> --derived derived/<上一步版本> --open
```

`--rebind`复用本地缓存OCR，不需重新识别或联网；缺OCR时保留警告，可另用 `--reocr` 补跑本地Vision。旧 `aoi.json`、原统计、原录制及预注册判定保持原样。

### 手动编辑

在控制面板生成/选择报告后，点击 **「编辑 AOI 并重新生成报告」**，或：

```sh
python tools/attention_report.py data/attention/<会话id> --edit
```

浏览器打开本机编辑页：空白拖框新建、已有框可拖动、四角可缩放、右侧改名/删除；Delete仅在本页面且不在输入框中时删除所选区域，没有全局键盘监听。**「保存手动 AOI JSON」** 导出只有名称和归一化矩形的JSON；**「保存并重新生成报告」** 直接写新派生版本、重新归属并打开新报告，原文件保留。修改后核对面板的当前报告也会指向新版本；旧AI解读不直接套到新统计上。

每份单会话报告旁都有 `aoi-editor.html`，图片、脚本全部内嵌，是可独立打开的离线单文件。单独复制/辅助服务已关闭时仍能编辑、导入和导出JSON；一键调用Python重生成须从项目的编辑入口打开。本机辅助服务只绑定127.0.0.1，随机令牌、来源及字段白名单校验，无外部资源或API请求；退出时关闭，默认空闲30分钟关闭（`report.editor_idle_s`）。没有任何图片随保存请求发送，只有当前场景的id/name/rect。

也可将下载的JSON用于离线命令：

```sh
python tools/attention_session.py data/attention/<会话id> --rebind --manual-aoi data/manual-aoi.json
```

手动矩形是完整替换，**空列表表示有意删除全部AOI**，不会被自动检测复活，也不会为吞并文字而改动手画范围。名称原样作为短标签，报告标注手动来源。

### 海报模板与多人

刺激物编辑器默认勾选「按图片SHA256复用」。模板只存矩形与名称，位于 `data/attention/aoi-templates/<原图片SHA256>.json`。以后整理同图刺激物、打开旧会话重新生成报告、多人汇总时自动使用；多人仍把每个人的原始已绑定注视按同一个模板重新归属，人数与等权分母不变。原来已生成的静态HTML不会追溯改写。

取消共享只影响该会话的派生版本；明确的会话专用手动范围优先于共享模板。多人汇总默认仍使用共享模板，或使用 `--aoi-template` 明确给定的统一矩形。要改汇总区域，先编辑任一单会话并共享，再重新汇总。共享模板独立于某个会话，删除单个会话不会自动删除共享模板；不再需要可删除该模板JSON。

新版手动JSON标明 `schema_version: 2` 与坐标空间：屏幕为 `full_screen_normalized`、按场景存 `scenes`；刺激物为 `image_normalized`，附 `stimulus_sha256` 和 `regions`。编辑器自动填写，不需手写SHA256。旧矩形列表/场景映射仍可由M9离线工具读取。

### 展示口径与审阅图

- 图上只编号主区域，自动短标签为「区域N：前8字…」，手动用所命名标签；图、表与关键结论保持一致，来源自动/手动明确。
- 屏幕模式的“未记录硬归属注视的区域数”仅统计有效注视停留最多的一个场景，并写明场景id，不跨场景相加。
- 屏幕模式顶部缩略图按有效注视时长排序；默认展开前三个，其他可点标题展开；不足0.5秒只保留总览。`report.scene_expand_count` / `scene_min_valid_s` / `short_label_chars` 可调。应用名读M9的 `app_name`，缺失显示“应用名未记录”，不再显示成图片刺激物。
- 竖版海报的场景图与AOI表并排。打印/PDF另设样式，折叠场景在打印时展开。

## 2026-11-05 实机后修正：误差尺度与单图说明

自动主AOI两边默认至少达到 `2 × sigma_x / sigma_y` 的图片归一化投影（`attention.aoi_min_sigma_scale: 2.0`）。不足的合并到包含它的容器或空间邻近区域；超过 `attention.aoi_max_primary: 12` 后继续按邻近合并。原区域作为不重复计时的子区域留痕；孤立小区域只剩一项时使用真实整图容器，不凭空造一个精确小热点。若误差大到超过半张图，只能退到整图尺度。手动矩形仍按用户给定范围保留，新编辑保存同样受主区域数量上限检查。

视觉容器占主导且OCR面积占比低（默认8%）时，以“图片：文字”或“图片区域N”命名，不再把图内小字直接当作内容主名；手动名称优先。相关阈值为 `aoi_image_text_fraction` / `aoi_image_visual_fraction`。自动合并会改变AOI粒度和排名，不代表原注视变准，也不重算校准或改变热图核尺度。

刺激物副标题只说明同一张图片的注意力分配，场景标题显示原图片文件名；新会话只记录文件名，不记录完整路径。旧会话缺失名称时显示未记录；用户可仅为派生结果补录，例如本次用户给定名称：

```sh
python tools/attention_session.py data/attention/20261105T084115.519756Z-369de32f --rebind --stimulus-name poster-report-scene.png
```

原会话不写回。该会话是误选旧报告截图后的密集表格用例，不是新海报精度实验；新版37个自动主AOI合并为3个，两边达到当前2σ，未记录注视的主区域从用户所报34个变为0个。有效注视时长和原始文件校验不变，证据 `data/report-preview/369de32f-v3-validation.json`。这只说明粗分区下有注视记录，不能解释为逐个单元格都看过。

用户本次实机报告打开时限/PDF/断网确认取消已记录；新DeepSeek真实调用仍待用户逐次确认后验证，预注册门槛不变。
