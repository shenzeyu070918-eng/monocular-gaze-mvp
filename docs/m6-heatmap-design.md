# M6 热力图实施方案与验收预算

基线 main `358f9e2`；仅 M6，不做 M5，不改变校准、核对、点击采集或网页评估的计算逻辑。

## 模块与数据流

- `gaze_core/heatmap.py`：按 capture_ns 驱动的 M2 注视检测、注视段累计/可替换预览、指数衰减、区域统计、核尺度与 RGBA 配色。无 Qt 或图像输入。
- `gaze_core/session_heatmap.py`：只读 Python 录制，仅完整精度核对时段；按每帧实际矩阵版本还原九点，旧文件按事件单调时间回退并说明局限。检测后在注视段内使用 M2 双向平滑，不跨无效、眼跳、间隙、核对或矩阵切换。
- `overlay/heatmap.py`：有界、非等待数值转交；网格、衰减、配色、导出均在后台。队列满只停止热力图并报告，不停止其他功能，不静默补算时间。
- `gaze_core/heatmap_export.py`：PNG/CSV/区域 JSON/Markdown 共用导出；只允许 data/heatmaps/ 新子目录。PNG 只有合成热图、区域网格、图例与说明，空白深色背景。
- Qt 层：查看时以默认1 Hz接收小尺寸QImage，预乘透明度并平滑放大；只有快照版本或可见标记改变才请求重绘，圆环始终画在热力图上面。未查看不生成/传递热图图片，不调用悬浮层更新；隐藏转换仅清除一次旧图。

实时：原始数值 → 当前九点修正 → M2 注视段 → 后台时长累加/衰减；仅查看时生成小图快照。持续中的合格注视仅作可替换预览，段结束后结算一次；不会按帧重复加权，不会延长到最后一次真实取帧之后。后台导出从累加器取数，不依赖显示快照。

离线：Python JSONL → 完整精度核对时段 → 历史矩阵修正 → M2 检测 → 段内双向平滑 → 不衰减的整段热图。核对目标只用于附近热量占比，不参与拟合、平滑或注视检测。

## 默认值与统计口径

配置来自 default.yaml，可用 local.yaml 覆盖：默认关闭、allow_uncalibrated=false、网格宽160、display_mode=on_demand、view_update_hz=1.0、alpha_threshold=0.15、半衰期 **60 秒**、最大不透明度 **0.4**。保留update_hz=4.0仅用于后台空闲/断帧检查，与重绘无关。未校准默认拒绝开启并提示「未校准，位置可能偏差约 10 cm」；强制开启持续标注。历史包含未校准贡献时标记保留，清空后重置。

Ctrl+Alt+H开关后台累加，Ctrl+Alt+V切换查看/隐藏；面板和托盘共用动作。on_demand开启只累加，continuous开启时自动查看，两者均默认1 Hz且可手动隐藏。仅使用已有Carbon/RegisterHotKey注册，不添加键盘监听。

RGBA统一按当前最大热量归一化：r=格子热量/当前最大值，t=alpha_threshold，正常透明度a₀=max_opacity×clip((r-t)/(1-t),0,1)。t>0时令u=clip((r-t)/t,0,1)，最终a=a₀×u²(3-2u)：从t到2t用smoothstep平滑接到正常值，t以下全透明，2t以上沿用a₀；t=0时直接用a₀避免除零。输出为8位RGBA，最终有1/255量化台阶。色相从黄到红，无深色/冷色低端。Qt用预乘透明度的平滑插值；PNG复用同一个RGBA函数，仍只画深色空白背景。阈值只影响显示、不修改数值；整图等比例衰减时相对色阶不变，不能将其当作数值未衰减。

高斯核只有一处尺度换算：**sigma = 圆环误差半径**。屏幕实测时 sigma_cm 取最近条件和矩阵匹配的 B 核对逐目标等权平均误差；没有结果则取圆环配置示意值。面板显示当前sigma数值、单位与来源。横纵分别除以实测屏幕宽高换成归一化 sigma；未实测时取相同的逻辑像素示意半径，不填写厘米。禁止在导出或 Qt 层再除以 2、3 等另行换算。屏内边缘高斯质量归一化。

PR #11边缘修正：实时与离线通过同一个`heatmap_position`函数，仅对热图位置作投影。中心到最近屏幕点的距离`hypot(dx/sigma_x, dy/sigma_y) ≤ 1`时夹回边缘并计入区域统计，超过才算真正屏幕外；角落同样按厘米/逻辑像素欧氏距离，避免两个轴各小于sigma却对角距离超标。原始坐标、I-VT及校准/核对数据保留未裁剪值。持续段预览与最终结算采用相同规则；`edge_clamped_s`与`outside_s`分别记录累计时长，夹回时长已包含在有效注视内，不再重复相加。

默认 3×3 非重叠区域，可自定义归一化矩形。以注视段中心归属，输出累计时长、有效屏内注视时长占比、相对会话起点的首次时间、进入次数、注视段数。连续同一区域的多个注视段不重复算进入；离开后返回或无效中断后重新进入才增加。矩形边界半开，屏幕最右/最下边包含在末区域。未覆盖区域、屏幕外时长单列。

实时网格单位为衰减加权秒/格，衰减在注视段时间区间内积分；区域统计为累计秒，不衰减。离线网格为秒/格。面板导出后台当前快照，不重新读取录制。清空重置网格、区域及统计起点。

## 数据格式与验收输入

Python frame 可选 `matrix_revision`；calibration 可选同版本号、匹配标记、误差半径与来源。保留原 schema 和数值白名单，新文件精确版本匹配；旧文件按 event_ns（没有则 server_ns）对齐，不读取当前档案替代历史矩阵。

验收使用悬浮层精度核对的 14 个目标，包含点击采集会话末尾核对。逐目标输出：整张核对热图在该目标附近的热量占比，以及该目标显示期间的附近占比。附近定义为半径 **1 sigma** 的物理圆（未实测时为逻辑像素圆），倍数配置为 target_neighborhood_sigma。邻域可能重叠，逐目标占比不能相加，也不等同精度合格率。各阶段保留自身核尺度来源。

## 性能预算与实机测量

以下均为**目标，尚非实测结果**：主线程原 tick 中位数 ≤0.35 ms、P90 ≤0.8 ms；查看时热图快照默认最多1次/秒；无图像或可见标记变化不触发热图重绘，未查看时无热图新增重绘。沿用 --profile-seconds，heatmap_update与heatmap_paint单列；隐藏时不调用heatmap_paint。结果包含剖析器开销，不能换算CPU，也不能代表WindowServer开销。

Mac同条件分别「后台累加未查看」/「累加并查看1 Hz」运行--profile-seconds 10，可用enabled=true配合on_demand/continuous在剖析开始前进入对应状态。每组记录Python与WindowServer的CPU/GPU、实际推理帧率、采样时长、屏幕尺寸/DPR、设备/线程配置、tick/update/paint中位数与P90。无绘制时写未调用，不填0；系统未提供GPU项写不可用。WindowServer包含其他窗口活动，两组保持应用、屏幕和交互一致。旧4 Hz版本实测已记验证记录，新版不得先宣称通过。Windows新增路径单独待验。

热力图表示「看了屏幕的哪个区域」，不表示「看了什么内容」；窗口切换和滚动会让同一位置对应不同内容。不截屏、不保存摄像头、人脸或屏幕图像，不上传个人数据。
