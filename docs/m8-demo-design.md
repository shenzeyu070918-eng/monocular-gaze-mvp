# M8 眼控交互 Demo

基线main `aa53452`（PR #13已合并），分支`m8-gaze-demo`，继续更新PR #14。本文按**2026-10-23批准的实机反馈修正**描述当前行为：沟通板保留，打地鼠退出菜单，新增星空凝视。校准、独立核对、热图和点击算法不改；不安装键盘监听，不采集屏幕或摄像头图像。

## 模块边界

- `gaze_core/dwell.py`：UI无关的停留/宽限/冷却状态机，输入滤波后的逻辑坐标与capture_ns，当前按钮独享0.5×误差半径粘滞区。800 ms有效停留、150 ms离开宽限、400 ms眨眼/无脸容忍、800 ms冷却均可配置；重复/乱序/未来/过期帧不累计，冻结时间不补算。
- `gaze_core/demo.py`：误差半径约束布局、分页、中心靶点练习、沟通反馈和选择撤销。按钮每轴≥3×对应误差半径、间距≥1倍；空间不足分页，不缩小按钮。旧game数值模型仅为历史录制兼容保留，不再作为菜单应用。
- `gaze_core/demo_drift.py`：会话内练习偏移，输入尚未叠加本次偏移的有效滤波坐标，输出归一化整体平移；无Qt、档案、文件、录制或硬件访问。
- `gaze_core/demo_coordinates.py`：完整内屏归一化、全局逻辑坐标及实际窗口客户区的双向换算。允许屏幕外点，不裁剪；DPR只作诊断，不重复缩放。
- `gaze_core/starfield.py`：确定随机源可注入的星空状态。`ingest`只接受真正的新采集帧，负责稳定凝视、蒙版和事件；`update`只做临界阻尼绘制位置、粒子运动、淡入淡出和局计时。快照数组脱离内部状态且只读，轨迹只在内存。
- `overlay/starfield.py`：worker独占模型和NumPy批量更新，单槽最新帧避免排队；准备颜色/大小分桶及QPolygonF数据。`StarfieldPainter`在主线程批量绘制星点和缓存光晕；`PaintEventTimer`从完整paintEvent入口测到QPainter.end之后，区分实际绘制与重绘请求。
- `overlay/star_run.py`：练习与星空worker之间的桥接；首次绘制确认才开始本局，重练期间暂停模型及本局时间，回来后不补算暂停期间的凝视或轨迹。
- `overlay/demo_session.py / demo_window.py`：匹配Python B/C、相机和任务互斥门控；保存/恢复原悬浮层与面板可见性。Demo全屏、不穿透，默认隐藏视线圆环，整块高亮按钮，文字居中对齐实际命中中心；中心练习小靶点和进度另绘。星空使用独立约60 Hz动画定时器，退出或不再动画时停止；沟通板只重绘变化区域。
- `overlay/speech*.py`：Mac系统say / Windows SAPI异步本地朗读，固定程序/脚本、文本经stdin，不生成音频文件；失败仅保留大字反馈，退出取消并回收。
- `overlay/actions.py / panel.py / hotkeys.py / runtime.py`：共享面板/托盘动作及既有Carbon/RegisterHotKey注册；`demo`默认Ctrl+Alt+D，`demo_practice`默认Ctrl+Alt+R。不监听全部键盘事件，Esc仅由Demo窗口处理；自身鼠标点击仍经OwnWindows排除。

演示样式、状态条常驻、九点成功保存后3秒“校准完成”、默认精简终端、data/logs详细来源以及--verbose均沿用本PR初版。网页入口、网页评估和日志行为不改。

## 坐标与练习修正

显示点复用个人修正→眼跳检测→One Euro输出。Demo判断以同一capture_ns新帧为准，不使用原始点、服务端接收或推理完成时间，也不另外改变滤波。转换为：归一化完整内屏 → 内屏全局逻辑像素 → 实际Demo客户区局部坐标；归一化1对应最后可寻址逻辑像素。菜单栏属于完整逻辑屏，不扣高度，也不使用availableGeometry替代完整geometry。

原生全屏Space切换期间、实际客户区原点/尺寸未覆盖完整内屏时不命中按钮。move/resize/窗口状态变化使几何缓存失效；只有实际元数据变化才重新计算。`--demo-debug`绘制修正前/后点、每个按钮中心十字及窗口边界，帮助区分几何错误与坐姿漂移。诊断点不代替原有选择数据。

练习按钮中心画小靶点，提示“看着中间的点”。用停留最后600 ms的有效滤波位置逐轴中位数，至少5个新样本、首尾跨度≥500 ms；偏移为靶点减中位位置。样本不足继续练习；只在实测屏幕宽高下换算偏移向量长度，≤3 cm才应用，超过则拒绝本次修正并提示重新九点。未实测时不应用新偏移，只说明无法验证厘米上限。

偏移只保存在本次Demo内存，不写个人档案，也不将练习目标加入九点或独立核对。面板显示“已修正 x.x cm”。重新练习从未叠加本次偏移的坐标重算，成功结果替换旧结果，不叠加；重练等待期间保留上次已接受偏移，失败不把超限候选应用上去。退出清除偏移。关闭初始练习不自动产生修正。

## 星空与时间

默认2000个星点/粒子共用固定池（含400个可复用烟花槽），3–5个自绘星座，默认4个。halo每轴半径=当前误差半径×1.5；吸引、回弹、亮度和烟花生命周期均由配置控制。临界阻尼弹簧仅决定视觉光点，重复动画帧不能产生蒙版、烟花或轨迹证据。

新有效采集位置在误差半径椭圆内稳定1500 ms触发烟花，之后冷却1000 ms。眨眼、无脸、过期、重复和乱序采集不增加稳定时长；短暂无效打断稳定区间，光晕按配置淡出。未来时间戳不会污染后续正常帧的排序。

显影蒙版在低分辨率标量布尔网格上记录有效采集光晕照亮的区域。星座足迹为星点圆盘与连线走廊的并集，覆盖率=照亮的足迹网格面积/总足迹面积；不是外包矩形。超过70%后记录一次发现事件，再渐显连线和名字。动画插值途中不显影。

首次实际绘制开始60秒一局；结束显示发现数和烟花数，按有效capture时间将内存轨迹快放5秒。重练暂停区间从本局与轨迹时间中排除；回放暂停后恢复剩余部分。回放结束后不再更新模型或持续重绘，退出join线程，不留后台动画。相机暂停、条件改变或退出全屏继续按现有生命周期取消并恢复原状态。

## 渲染与性能口径

先使用不透明QWidget + QPainter；后台NumPy批量计算、只读快照与绘制分桶，Qt仅批量drawPoints/少量星座线条、缓存光晕和文字。约60 Hz是动画目标，实际Qt定时调度和投影合成必须实测；是否需QOpenGLWidget由数据决定，不提前宣称满足预算。

`starfield.frame_budget_ms`默认8；**完整paintEvent耗时中位≤8 ms是待验目标**。关闭Demo时只写一次`data/performance/*-stars.json`，不每帧主线程落盘：

- `worker.update`：模型更新、快照及批量绘制数据准备的真实墙钟耗时，包含中位/P90、实际更新fps、长帧数量；不含Qt绘制。
- `painter.draw`：星空QPainter实际绘制耗时及实际绘制fps，未把`update()`请求当绘制。
- `paint_event`：完整paintEvent，含QPainter建立/结束、背景、星空、标题/底部文字及调试层；报告中位/P90、实际fps、预算和超预算帧数。
- `painter.update_plus_draw`：本快照准备与绘制耗时的数值相加，两者运行于不同线程，**不是完整帧墙钟耗时**，不作8 ms验收依据。

这些数字不是摄像头端到端延迟或CPU百分比，也不包含WindowServer合成耗时。实机另用现有--profile-seconds记录普通回调，并分别测Python/WindowServer CPU/GPU、投影模式和采样时长。

## 数值录制

沿用单会话、后台队列、flush及白名单，不自动开录或新建会话，不改变评估CSV。

- `demo_selection`：保留triggered/confirmed/undo、run_id/selection_id、B/C、阶段、固定目标编号/归一化坐标、capture_ns/event_ns、有效dwell_ms及selection_ms。只记录选择数值，不记录沟通文字。触发先为待确认，1秒内Esc追加撤销，完整观察窗口后追加确认；异常中断/提前停录留下待确认，不虚构无误触。
- `demo_summary`：沟通选择与退出汇总。练习、翻页不计入应用成功数；汇总触发均值不能代替实机人工核对成功项的平均值。旧app=game记录仍可replay。
- `starfield_event`：run_id、B/C、event_ns、event_code、constellation_id、firework_count、found_count、elapsed_ms。代码1烟花、2发现、3进入回放；星座仅数字编号。
- `starfield_summary`：run_id、B/C、event_ns、烟花/发现数量、星座编号数组、elapsed_ms、completed和数字reason_code；未完成与正常结束区分。

不写轨迹、蒙版、粒子数组、星座名字、沟通内容、语音、按键信息、屏幕或摄像头图像；练习偏移不写档案。原有frame数值录制仍按既有白名单工作，Demo不会额外保存视觉内容。

## 验证边界

新纯逻辑测试覆盖漂移方向/阈值/无实测/不足样本/重练替换、完整逻辑屏/负原点/Retina/全屏Space几何、显影足迹覆盖率、粒子有界/暂停/批量更新、弹簧只绘制、帧去重/时钟/5秒回放，以及数值录制白名单。Qt合成测试覆盖worker生命周期、只读快照、整块高亮/隐藏圆环、诊断与实际全paintEvent计时；现有校准/核对原始取样、点击、热图回归照常执行。

用户本轮反馈为沟通板不舒适并追圆环，同次九点拟合残差0.16–0.88 cm、平均0.52 cm；**这是九点自身拟合残差，不是独立核对精度**，不能据此宣称坐姿漂移或显示偏移已排除。Mac/Windows真实可用性、完整星空、投影坐标、60 fps和≤8 ms预算均待实机；结果与软件测试分列，不预填成功率或性能数字。具体清单见验证记录。
