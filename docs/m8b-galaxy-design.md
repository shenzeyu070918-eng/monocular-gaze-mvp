# M8b 眼手星系：实现与边界

基线：PR #14 合并后的 main `5ec3971`；分支 `m8b-galaxy`。本次只实现 M8b。

## 模块与线程

| 模块 | 职责 |
| --- | --- |
| `gaze_core/galaxy.py` | 参数验证、手掌聚合特征、张开度平滑/滞回、三帧接管与500 ms退出、采集时钟驱动的图案循环 |
| `gaze_core/galaxy_protocol.py` | 纯数值帧白名单、浏览器原始几何验证及调用 DemoCoordinates、性能消息校验 |
| `gaze_core/demo_frame.py` | UI只切换处理器引用；推理线程加载/调用/关闭当前处理器 |
| `overlay/galaxy_processor.py` | 同一个已选中OpenCV帧上的Hand Landmarker、显示坐标+本次练习偏移、数值推送 |
| `overlay/galaxy_bridge.py` | 临时127.0.0.1 HTTP/WS服务、随机令牌、Origin/Host校验、单客户端、只留最新待发送包 |
| `overlay/galaxy_browser.py` | 独立临时Chrome资料目录与回环CDP窗口控制；不连接用户现有浏览器资料 |
| `overlay/galaxy_session.py` | 非阻塞启动、轮询、退出清理及数值性能日志 |
| `static/galaxy/` | 本地three.js r180、GPU双缓冲粒子、辉光、四种图案、单向降档及帧间隔统计 |

采集线程仍是唯一打开/释放摄像头的一方。原始录制/核对数值出口先运行，M2个人修正+眼跳+One Euro后，再将**同一帧**交给可选Demo处理器。手势VIDEO检测同步在现有推理线程执行，最多两手、最多每个推理帧一次；不增加摄像头、不向原始结果插入手部关键点。退出/暂停后在推理线程关闭模型。低帧率和手势CPU代价待实测，默认推理限速及设备选择不变。

桥、Chrome控制和退出写日志各用工作线程；Qt回调只处理队列事件与状态。桥的发送槽容量为1，慢浏览器覆盖旧数值包，不反向阻塞摄像头。渲染按rAF运行，临界阻尼弹簧只插值画面，不创造新视线证据；图案停留判定只用不同的真实capture_ns。

## 时钟、数值格式与隐私

WS `/ws` 先发送 `{type: auth, token: ...}`；只接受本次127.0.0.1页面的Origin和本次随机令牌，一个会话只接一个页面。令牌通过URL片段传递，页面读取后清除，不进入HTTP请求、访问日志或性能文件。关闭时服务退出、令牌失效。浏览器不请求摄像头；响应的Permissions-Policy禁止相机、麦克风与屏幕捕获。资源全部本地，无CDN。

每个 `frame` 的 `data` 必须恰好包含以下字段（全部是有限数值或数值数组，状态用数字编码）：

| 字段 | 含义 |
| --- | --- |
| v / seq / viewport | 协议版本1、源帧序号、已验证的视口版本 |
| capture_us / completed_us | 相对当前处理器起点的采集/数值处理完成单调微秒，避免JS纳秒整数精度丢失；不能与浏览器performance.now相减 |
| gaze_valid / gaze_state | 有效标记；0跟踪、1眨眼、2无脸、3其它异常 |
| fixation | 0未知、1注视、2眼跳 |
| xy / radius | Python已换算的视口局部逻辑像素坐标和误差椭圆半径；不裁剪 |
| control / hands / distance | 接管标记；每手 `[镜像x,y,张开度,捏合比,vx,vy,滞回状态]`；两手的归一化距离。速度单位归一化坐标/秒；捏合比以掌宽归一化 |
| pattern / intro | 0螺旋、1心形、2配置文字、3地球轮廓；开场标记 |
| hand_ms / hand_available | 本帧手势处理耗时及手势模型可用标记 |

不发送/保存视频、图像、base64、21点手部骨架、屏幕内容、窗口标题或键盘信息。退出的 `data/performance/*-galaxy.json` 只含数值帧率/耗时、降档计数、丢包计数与错误原因，不存视线或手势轨迹。已有JSONL录制仍走既有数值白名单；练习事件只增加应用枚举galaxy。

## 进入、坐标与退出

1. 匹配Python九点或粗校准后，从面板/原生Ctrl+Alt+D选择默认“眼手星系”。沟通板代码保留，演示菜单只提供星系和Qt星空备用。
2. 先使用原Qt练习页获取会话内漂移修正；规则、3 cm限制和不写档案行为保持原样。通过后隐藏Qt窗口，再启动本地桥及浏览器。
3. 优先独立Chrome app窗口；回环CDP先按内置屏逻辑矩形定位，再请求原生全屏。临时资料目录、进程均属于本次Demo，关闭时只关闭此进程。找不到Chrome才打开默认浏览器，并提示手动移至内屏/全屏，退出可能需手动关页。
4. **点击进入星系**：浏览器上报screenX/Y、inner/outer尺寸、DPR、screen尺寸、缩放，以及**同一个点击事件**的screenX/Y与clientX/Y。Python用事件的screen−client确定实际客户区全局原点，再复用DemoCoordinates；不以外框screenY猜菜单栏/刘海高度，不在JS重做全屏归一化换算。DPR须与QScreen一致，页面保持100%缩放。
5. Chrome系统全屏状态由本次CDP通道确认；默认浏览器的首次点击只请求Fullscreen API，切换完成后必须再点一次，避免拿切换前的点击几何。客户区必须完整在内置屏内，可从y=32开始、高950；不要求覆盖982高的完整屏。几何/缩放变化立即停止消费坐标并要求重点击，错误可见，不静默命中。
6. 验证通过后开始约2 s混沌→螺旋汇聚；结束前不响应视线/手势。此后视线定位、手势控制形态，释放后恢复图案。1.5 s稳定凝视循环图案，切换期间重新计时。
7. 页面内Esc是页面局部事件，不安装全局键盘监听。正常退出恢复先前圆环/面板可见性，手动暂停、屏幕变化、条件变化沿用既有取消流程；重练先关闭网页并回到Qt练习。WebGL2/连接失败提供Qt备用选项。页面只上报本页是否有焦点，前台Demo内点击标记own_ui，不查询其它应用，也不把切走后的整块屏幕持续标作本程序点击。关闭页短暂断连先等待专用Chrome退出状态，意外断连提供备用；几何失效后有独立的新超时窗口供重新点击。

## 渲染与性能

GPUComputationRenderer以浮点纹理双缓冲更新位置/速度；UnrealBloom+OutputPass，程序生成星云/多层星点。50,000默认、100,000可选；`galaxy.text`默认BME，可1–80字。纹理、shader、辉光和Chrome实例退出释放。2D文字画布只栅格化配置的展示文字，不读取屏幕内容。

连续低于50 fps满3 s，先100,000→50,000；已为50,000时逐次降低渲染像素比，最低0.75；不自动升档。debug显示当前粒子数/像素比/降档次数。阈值、时间、亮度、辉光、弹簧等均在galaxy配置。rAF帧率使用真实帧间隔，不用限制过的物理积分dt；隐藏页不用于降档。60 fps是目标，软件模拟不构成Mac GPU或投影验收。
