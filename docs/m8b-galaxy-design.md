基线：PR #14合并后的main `5ec3971`；分支`m8b-galaxy`，PR #15。画面检查点已获用户确认，现按批准的重做方案接入粒子行星、视线与手势。软件检查与实机验收分列，不以合成输入或软件渲染代替真实成绩。

## 数值协议、时钟与隐私

WS `/ws`先验证本次随机令牌与127.0.0.1 Origin/Host，一个会话只接一个页面。令牌来自URL片段，读取后从地址移除，不进入HTTP请求/日志/性能文件；关闭时失效。浏览器不请求摄像头；Permissions-Policy禁止相机、麦克风及屏幕捕获。固定本地three.js r180/MIT，无CDN。

每个v5帧恰好包含以下有限数值或数值数组：

| 字段 | 含义 |
| --- | --- |

| capture_us / completed_us | 相对处理器起点的单调微秒；不能与浏览器performance.now直接相减 |
| gaze_valid / gaze_state / fixation | 有效标记；0跟踪/1眨眼/2无脸/3其它异常；0未知/1注视/2眼跳 |
| xy / radius | Python已换算的视口局部逻辑坐标和误差椭圆半径；不裁剪 |
| control / hands / distance | 接管标记；每手[镜像x,y,平滑张开度,捏合比,vx,vy,滞回状态]；双手距离。速度为归一化坐标/秒，捏合比以掌宽归一化 |
| pattern / intro | 0行星/1星系/2配置文字；开场标记 |

| burst_revision / burst_active / burst_elapsed_ms / burst_source | 打散事件版本、包络活动0/1、采集/动作时钟经过毫秒、来源0无/1闭眼/2页面局部手动动作 |

| hand_ms / hand_available | 本帧手势处理耗时、模型可用标记 |
| hand_detected / hand_openings / hand_error | 本帧检测手数与原始聚合张开度（接管前也报告）；0正常/1加载失败/2检测失败。不发送关键点或错误路径文本 |

边缘/可选角落选择用Python capture_ns；推近的停留用同一采集时钟的capture_us，仅不同采集帧增加证据，断档/开场不计入；短暂离开/眨眼/无脸在默认300 ms宽限内冻结并保留进度，超过才清零。rAF只插值绘制，绝不当新样本。帧新鲜度使用Python处理时长加浏览器接收后的performance.now时长；不用可能早于WS收到消息的rAF时间，避免负年龄。该数不含无法跨时钟直接测量的传输时间，不称为端到端延迟。

不发送/保存图像、base64、21点手部骨架、屏幕内容、窗口标题或键盘信息。正常日志只含数值性能/计数和错误原因，不存视线/手势轨迹；已有JSONL沿用数值白名单。测试图仅是程序自己的合成画布和用户提供的参考，不读取真实桌面或摄像头，放在忽略的data/下。

## 进入、几何与退出

1. 匹配Python九点或粗校准后，从面板/原生Ctrl+Alt+D进入“眼手星系”；Qt星空备用，沟通板代码保留。
2. Qt练习先完成仅本次会话的漂移修正，原有规则/3 cm上限/不写档案保持原样；随后打开独立Chrome、定位内置屏、请求原生全屏。
3. 点击进入：同一点击的screen−client给出真实客户区全局原点。Python复用DemoCoordinates，将完整内屏归一化→全局逻辑→视口局部，含刘海下方较小客户区。DPR须匹配QScreen，缩放100%，客户区完整位于内屏；JS不重写这套映射，只做WebGL视口投影。
4. Chrome全屏由专用CDP通道确认；默认浏览器首次点击请求Fullscreen API，切换后再点一次。窗口/缩放变化要求重点击，错误可见。找不到Chrome提示默认浏览器手动定位/全屏和退出限制。
5. 约2秒混沌→行星汇聚后才响应输入。Esc是页面局部事件；重练/暂停/条件变化/关页关闭本次桥、手势模型和专用Chrome，恢复原悬浮层；失败提供Qt备用。不安装键盘钩子，用户其他浏览器不关闭。
6. 页面只报告自身焦点，Demo内点击继续标记own_ui；不查询其他应用。已有校准、核对、热图、点击/M5取样和统计不改变。

## 画面与交互

默认8万球粒子在球内按体积均匀分布，不用球壳替代；暖金三色、按投影视线的impact parameter做limb增亮，核心小而亮。少量低频翻涌持续运动。星环15万粒子，内半径1.4R、外半径8R：面密度按r^(-2.6)，用拒绝采样加入两道可配置窄低谷；亮度由内缘白逐渐衰减到外缘青蓝，角速度按r^(-3/2)，有厚度和少量游离再返回。默认约1.5%颗粒有长尾尺寸/亮度、微光晕与慢闪；远点更小更暗。浮点颜色缓冲、ACES曝光、小强度高阈值辉光避免大片过曝。

行星始终居中，视线的视口位置驱动有限俯仰/方位范围的临界阻尼相机弹簧；三个场景均按采集时间停留1.5秒后推近。行星仍用射线/球体；银河/文字改为投影核心圆：max(核心世界半径的投影×zoom_core_scale, 误差逻辑像素半径×2.5, 视口高×0.12)。银河核心世界半径为galaxy_zoom_core_ratio×galaxy_radius（默认0.35），文字取实际字形包围盒较小半边。仅图形投影在JS计算，屏幕/客户区映射仍由Python统一负责。CaptureDwell只在不同采集帧、连续命中间增加计时，离开≤300ms冻结；推近后仍处于1.6倍范围内保持，超出持续>400ms才拉回。行星退出用1.6倍球体。眨眼/无脸在对应宽限内冻结，真实断档清零。核心细SVG圆弧显示累计进度，zoom达到0.95后淡出；不是额外WebGL pass。切场景重置推近证据与推近弹簧，不能继承上一场景的缩放。行星运镜保持原样。银河将水平视线弹簧输出作为粒子绕盘面法线的旋转，默认±45°，相机不绕行；竖直只调俯仰±8°，夹角最低20°，核心始终lookAt原点，默认按银盘最紧投影边界铺到视口110%自动取景，核心停留后距离降至当时默认距离的0.5倍、辉光增量随zoom最多0.65，允许裁外缘。文字从正面起始，默认方位±4°、俯仰±3°、无翻滚。

文字取景对实际包围盒8个三维角点求相机距离约束：d≥n·p+|r·p|/(tan(fov/2)×aspect×fraction)以及竖直对应约束；包含字形厚度/流动范围和手势缩放。near取配置与90%取景约束中的较大值，far按原远近比例相应拉远；窗口变窄时也不裁字。可测的scenePose/textFitDistance与Qt/Python屏幕映射分离。

行星环的弱引力井保持；银河/文字取对应平面交点，以 `galaxy_well_attraction/text_well_attraction` 分别配置，默认均为0。聚光灯只提亮、轻微闪烁、增大点尺寸；世界半径=误差逻辑像素半径×2tan(fov/2)×交点视空间深度/视口高度，再除以手势模型缩放成为局部半径。正式GPU顶点读回验证零吸引时位置完全不变。文字在生成mask时按字形区间编号并收紧到实际墨迹包围盒，粒子静态携带编号和字心；至多80个字形权重由弹簧更新。命中字母整体相对字心缩放1.08、z浮起0.12世界单位、提亮，不改变字母内部相对结构；其它字母不动。该世界单位不是厘米。射线/临时向量复用，不逐帧构造Three几何。默认左右整高边缘条各12%，累计1.5秒，左上一个/右下一个；scene_switch_mode可选corners恢复20%角落向前循环，或off关闭。两者复用同一状态机、版本和完成ACK；不使用锚点半径限制，边缘光条/角落圆弧按对应模式显示。轻微越界点到最近边缘的椭圆距离在max(误差半径,区域比例×视口尺寸)容差内时仅将命中位置夹回，原xy和debug uv不裁剪。300 ms宽限冻结进度，跨区域不合并证据，真实采集断档清零；角落青白细弧在有效帧上更新、完成后淡出，场景过渡/冷却保持。星系是有厚度的金核/蓝紫旋臂和暗尘带，文字填满笔画、只在笔画内流动。

张开度经过中位数、指数平滑和Schmitt滞回，三帧后接管。张手使环与银河沿盘面径向/切线散开、附少量高度扰动，文字采用由aSeed独立生成的球面均匀随机方向，叠加解析卷曲（curl(sin(y),sin(z),sin(x))），与粒子相对字心的位置无关；xy默认散开一字宽，z最大0.04字宽，点上限2.5逻辑像素。种子在全局手势包络中错峰，局部smoothstep同时缓动散开/回收；每帧只有一个当前位置，不叠加旧字形或历史纹理。银河散开距离默认2.4个银河半径（上一版两倍），另加旋涡；距离/高度按场景分别配置（环单位为球半径、银河为银河半径、文字为半个文字宽度，文字高度为平面法线z方向）。强度随张开度；握拳使散开量归零。松手也平滑回到各粒子的当前轨道，不冻结或突然跳回旧时刻；挥动速度短时提高轨道相位速度，双手距离有限缩放。仅视线时仍保持完整画面。模型不可用或失败保留视线，debug明确原因。

## 进入时偏移刷新

先用服务端探针发送/收到的perf_counter_ns中点，对齐浏览器回调performance.now；客户端点击时间戳沿同一浏览器时钟送入Python。往返>entry_clock_max_rtt_ms（默认100ms）拒绝；半往返为保守对齐不确定度，不当作观测到的网络/回调延迟。无有效探针、未来/过旧点击均保留原偏移。真实按钮中心来自getBoundingClientRect；仍由已验证DemoCoordinates转换为完整内屏归一化坐标，含刘海偏移。

推理线程在等待进入时仅复制原始raw/head_degrees/origin_m与display.unfiltered等短数值，绝不持有image。使用M4的raw_fixation_state与sample_clicks，窗口entry_window_ms默认[300,0]ms，min_frames/覆盖/有效率/头姿/稳定/离群门槛完全沿用config/implicit_experiment.yaml，不放宽。用被接受的同批帧的个人修正后未滤波坐标中位数对齐按钮中心，得到替代练习偏移的绝对会话偏移；未实测尺寸、样本不足/无效或总范数>entry_max_correction_cm（3cm）则不采用。进入后停止该采样，退出清空缓冲；不改矩阵/档案/M4与M5样本。debug、启动日志和退出性能JSON仅记录采用标记、候选/当前偏移cm、样本数、原因码和RTT，不存帧或点击目标位置。

## 闭眼与场景汇聚

闭眼来源复用引擎现有分类：先发现脸，再计算左右眼EAR平均值，低于 `inference.blink_threshold`（默认0.14）返回blink。检测器不另设模型或阈值，不把视线无效当闭眼。先观察睁眼，再以连续blink采集帧的首尾capture_ns差≥600 ms作证据；只在随后睁眼帧触发，睁眼前间隔不补算。geometry_invalid/screen_unconfigured在引擎中已通过EAR，所以可作为睁眼，但不能当有效视线。无脸、无效状态或>stale_ms的断档取消本轮并要求重新睁眼；重复或倒退时间戳不增加证据。自然短眨眼不触发。

闭眼和B键共用事件版本/冷却：包络300 ms上升、400 ms保持、其余缓动回收，总2500 ms，触发间隔3500 ms；手势和包络用max合成。页面只能请求通用burst动作，不发键名。Python计时/计数，网页按已收到的elapsed插值视觉包络，不能创造闭眼证据。开场和汇聚期间取消蓄力/包络，键盘也忽略。

Python PatternCycle统一持有旧/新场景、版本与切换起点。旧形状先0.5秒从intro=1逆向散成混沌，换几何后用相同intro逻辑1.6秒汇聚；期间视线/手势/换景/B均不生效，不排队。网页在实际绘制完之后发 `{type:scene_done,viewport,scene_revision}`，Python同时核对版本、视口、最短总时长，才解除角落冷却；未确认时锁定可超过2.1秒，防止慢页提前接管。同版本的已完成状态不会被迟到active快照复活；旧视口帧在发布端和页面均丢弃。首次config声明v5，不匹配要求重启Demo；已有数值录制格式不变。

## 银河造型与长期稳定性

主臂中心为 θ=log(r/r0)/tan(pitch)+kπ（k=0,1），默认pitch=15°。盘面半径按r·exp(-r/h)采样，h=0.34R；主臂高斯横截面宽度随半径及静态噪声变化，短分叉只占臂粒子的12%。非核球/亮团盘面中30%为弥散盘，避免纯黑间隙；低密度/低亮的臂内侧带近似尘埃。核球为半径0.32R、轴比0.55的椭球，向外平滑变淡、颜色与暖金行星一致。0.9%粉品红亮团沿旋臂零星分布，整体保留长尾亮颗粒；外臂亮度有静态破碎调制。

世界位置以同一个Ωt刚性旋转。小漂移s=1+0.006 sin(tω+phase)，令r'=rs，θ'=θ+log(s)/tan(pitch)-Ωt，故θ'-log(r'/r0)/tan(pitch)恒定；没有随半径不同而累计的角速度。手势只改变motionTime，同样保持此不变量。颜色/发光权重在场景创建时烘为静态RGBA属性；CPU不逐帧循环粒子，GPU不再逐粒子计算尘埃/核球颜色，无新增实时绘制pass或纹理目标，23万与降档预算不变。

预览动态导入的GPU检查从正式particleVertex注入一个只读输出，在同一WebGL2上下文用transform feedback读取约1.6万主臂点；关闭注视/甩散，仅检查造型运动，finally清理临时程序/缓冲并重置Three状态。它不在正式draw中运行。基线8秒，对60/300/600及最大手势加速对应2400秒计算：去掉统一旋转与对数漂移后的相位RMS、8个半径区间的平均角变化、拟合螺距变化；任一超配置默认2°则失败。测试还用旧差速公式作反例，必须被拒绝，防止只验证新公式自身。报告与正面/斜视时间拼图在忽略的data/reference/render_check/。设置uniform时间不等于实际运行了对应时长；本屏/投影连续演示及约120 FPS仍需实测。

## PR #15实机反馈修复：调试画刷与统一场景状态

Qt DemoWindow._debug在画视线点后显式设NoBrush才画边界；外层save/restore保留调用方状态。星系/沟通板练习与Qt星空回退共用该修复，StarfieldPainter内部也有save/restore，其他目标绘制不在填充画刷后画窗口边界。离屏测试实际检查调试色面积与靶点白像素，防止再出现纯色整屏。--demo-debug经DemoSession→GalaxySession→bridge.debug→Chrome --app URL保留?debug；网页history.replaceState只删除令牌片段。

场景状态统一由GalaxyBridge持有PatternCycle，在同一把锁下处理推理线程的feed和WS线程的step。网页局部→/空格发下一步、←发上一步，只发送{type:scene_step,direction:±1,viewport}控制动作，不发送/记录键名或键盘内容；不新增全局钩子。服务立即回复scene状态，推理不出有效视线时按键也能换景；下一次凝视从同一pattern继续。每次切换带scene_revision与旧/新场景和毫秒进度，网页拒绝旧版本覆盖，新视口会同时重置场景与闭眼状态。切换中不响应反向按键，完成确认后才允许下一次操作。过期视口按键请求被忽略、未知字段或非±1方向被拒。

宽限只冻结已获得的有效停留；恢复后的第一帧不把离开的间隔补计为有效视线。进度弧不在rAF中增加证据。debug显示未裁剪视口uv、带符号越界量、角落/宽限/冷却、有效毫秒数/进度和最近清零原因。协议仅增加有限数值字段，原始录制/校准/核对统计不变。
