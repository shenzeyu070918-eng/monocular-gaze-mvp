## 操作与计时

先打开 Finder 和系统「备忘录」。`attention.guide_excluded_app` / `guide_excluded_bundle` 可改用别的应用；缺少时临时把显示名及bundle ID加到**本次后端**排除名单并提示，结束后还原，既不改默认名单也不写local.yaml。面板暂停快捷键提示读取实际配置。

点引导后自动采30秒不录制CPU基线。在本地页点「打开右侧彩色测试标签」，浏览器准备第二页后按 `⌘⇧[` 返回左页，再全屏、100%缩放开始。弹窗/权限准备不占注视计时；等首个画面和浏览器前台就绪，UserNotificationCenter/NotificationCenter/SecurityAgent等系统弹窗消失后，才发出首个目标。

默认总长36秒（`attention.guide_action_s: 4`，可延长，不可少于4）：

| 时间 | 具体动作 |
| --- | --- |
| 0–16秒 | 8块各看2秒，仍用原尺寸及取样窗口 |
| 16–20秒 | 向下滚过至少半个视口，看见下方编号9–16的内容，停住≥1.5秒 |
| 20–24秒 | `⌘⇧]` 到右侧彩色测试标签，停住≥1.5秒，再 `⌘⇧[` 回来 |
| 24–28秒 | `⌘Tab` 切 Finder 等普通应用，停住≥1.5秒，再返回 |
| 28–32秒 | 切到备忘录，停住≥1.5秒，再返回（后端暂停截屏） |
| 32–36秒 | 按配置的暂停快捷键，等1秒，再按恢复 |

计时由Python单调时钟线程推进，切标签/应用不会因网页后台节流而卡住。操作提示同时放在本程序的持续录制条上（被原生过滤排除），离开网页仍可看到。CPU继续保留30秒窗口：任务计时前快照至第30秒的实际快照，报告墙钟时长，不把36秒假称30秒，也不改CPU门槛。

仅出现提示不证明已执行。滚动需观测到**该阶段内**至少半屏位移；第二页需实际前台可见≥1.5秒；普通/排除应用需原生前台驻留≥1.5秒；排除还需录制状态`excluded_app`，暂停需`user_paused`和后续恢复。没有动作证据时明确列为「未执行/未观测」，不能伪造通过。网络/定时器未能及时观测到也保守报缺证。

结束并整理后，自动带回控制面板，直接显示硬归属、3/3切换、自窗口零残留、额外CPU四项及缺失步骤。自窗口没有受控证据时为「未验证」，不会因图上没看到圈而判通过；四项不取代人工确认。

## 一次受控自窗口测试（另行运行，不用相机）

先退出原悬浮层，避免另一进程的窗口干扰，再运行：

```sh
./.venv/bin/python tools/check_attention_windows.py
```

工具用独立子进程画固定底图，主进程让真实OverlayWindow（圆环、热图、状态标记）、录制提示、ControlPanel、弹出菜单保持可见；**没有截图前hide**。第一次过滤后，在同一后端存活期间再新建一个窗口复测。分别检查：

- 未过滤图中每种窗口区域有实际标记像素（缺任何一项都不能通过）。
- 原生应用过滤后的受控内框与固定底图逐像素比较，残留像素要求零。允许3/255的通道色彩转换容差，不是允许残留标记。
- 窗口均持续可见；后创建窗口同样被排除。底图或可见性不满足时失败且不保存截图，避免保存其它桌面内容。

结果写 `data/attention-window-check/latest.json`，仅通过时保存受控内框对照PNG。终端明确打印通过/失败。工具为了隔离窗口排除，前台身份固定为受控底图，不替代引导的真实应用排除步骤。Windows本工具未实现。

随后跑引导，会把尺寸匹配、证据字段完整的该结果写入新会话的`self_window_test`事件。历史会话/原始记录不会自动改写，屏幕尺寸不匹配或文件残缺保持未验证。
