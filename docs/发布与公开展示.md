独立gh-pages分支根目录发布，不能将整个main或data目录部署。tools/build_pages.py只从默认公开配置（use_local=False）构建：18个预览ES模块及three.js依赖、本地CSS/固定配置、合成示例报告、导航。入口直接加载preview.mjs，不部署app.mjs/entry.mjs，不访问摄像头、麦克风、屏幕或本地实时桥。三方许可随vendor保留。

报告来自自绘海报+合成注视，显著标注“合成示例，非实测”；图片内嵌，移除本机绝对路径与本地编辑服务链接。没有个人录制、截图、人脸/摄像头内容、密钥或档案；不表示M10已合并。历史SHA映射只含对象编号，不含个人录制。

复现时输出必须为空，避免旧目录混入个人文件：

```sh
.venv/bin/python tools/build_pages.py --output data/pages-new
```

本地核验完成后仅上传该目录至独立发布分支。GitHub Pages Source为gh-pages /，不需要发布产品代码。更新站点需再检查模块白名单、报告合成标记、路径、网络请求及许可证，不能从本机data批量复制。

本机隔离Chrome/SwiftShader检查：项目子路径下三场景就绪、报告可打开、摄像头调用0、WebSocket0、外部请求0、JS异常0。此为软件检查，不代表现场GPU帧率；真实大屏/Windows/多人范围仍待测。
