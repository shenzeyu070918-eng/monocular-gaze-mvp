## 自动化回归

在项目根目录、已安装环境中运行：

```sh
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests
node --test tests/*.mjs
git diff --check
```

Windows Python 命令改用 `.venv\Scripts\python.exe`，离屏变量可通过 PowerShell 的 `$env:QT_QPA_PLATFORM="offscreen"` 设置。部分平台原生检查不能由另一平台的模拟测试替代。测试不应保存或上传摄像头/人脸图像；AI 测试只用模拟 provider。
