# 验收入口与已知边界

本页索引真实记录，不替代原始验收或重新选择阈值。A=未个人校准，B=九点，C=点击粗校准；网页与 Python 链路分开，校准点拟合残差不当独立精度。

## 三分钟体验（已安装、权限正常）

1. 无摄像头：在根目录运行 `.venv/bin/python tools/preview_galaxy.py`，浏览器打开终端地址 `http://127.0.0.1:8768/?preview`。Windows 改用 `.venv\Scripts\python.exe tools/preview_galaxy.py`。预览只接合成输入，可切行星/银河/文字、鼠标模拟视线、O/F/N 张手/握拳/无手及 B 打散；退出终端 Ctrl+C。
2. 本机体验：双击对应悬浮层脚本 → 面板九点校准（必要时补看）→ 精度核对，观察 A/B 结果，按 Esc 可取消任务。不以校准残差代表独立测试成绩。
3. Mac 主动分析：有效 Python 九点档案下开始短会话，暂停、恢复、结束，在面板找到本地目录，核对场景/注视/AOI/热图。第一次权限操作和安装不算三分钟体验的保证。

完整 M9 验收包含 CPU 基线和不限时动作，不能缩成三分钟的正式承诺。[原预注册](m9-acceptance.md)不修改，当前操作方式见[引导修正](m9-guide-revision.md)和[使用手册](使用手册.md)。
