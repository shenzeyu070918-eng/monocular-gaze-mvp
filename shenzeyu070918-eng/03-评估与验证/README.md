# 03 · 评估与验证

以[验证记录](../../验证记录.md)为原始结论入口，[简明验收入口](../../docs/验收入口.md)汇总已测条件、A/B/C分组和未验证项。当前主要是Mac单用户，不外推到其他用户或Windows。

- [M9预注册](../../docs/m9-acceptance.md)：实施前锁定，未事后修改；正确硬归属≥60%、指定切换3/3、自窗口零残留、额外CPU<单核10%。[后续引导修正](../../docs/m9-guide-revision.md)改变操作流程，不改门槛。
- M9四轮硬归属80.4% / 85.3% / 76.2% / 66.7%，仅第四轮完整通过，最新余量6.7个百分点。四轮非同条件稳定性实验，不用平均值替换验收。
- M4预登记规则、筛选口径、事后探索及M5范围取舍见验证记录M4/M5章节及[空白报告模板](../../docs/templates/implicit_calibration.md)。不将“B+点击偏移”探索纳入预登记判定。
- M5独立核对C 2.957 cm、A 12.154 cm；回放与实机分开。max_clicks=120是单次会话暂定选择，一次独立实机核对后暂不调整。
- M3b CPU优化用户实测30帧约65%、15帧约45%（Mac CPU 2线程）；进程总线程不等于PyTorch线程数，其他模式另测，不作为跨机指标。
- 校准残差、独立核对、硬AOI归属是不同指标；实际坐姿、边缘和档案时效影响结果，不加单人固定角度修正。

全部数值保留原记录，原数据位于被忽略的data，不为课程展示上传个人录制。M10预注册与实现留在PR #17，不并入本轮仓库整理。
