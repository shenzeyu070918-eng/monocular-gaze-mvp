## 关键结论（含没做到的部分）

- Mac Python九点B核对曾为平均2.525 cm、补看后另次2.336 cm；是各次独立条件，不能与校准点残差混用。厘米级估计只适合大块。[评估索引](03-评估与验证/README.md)。
- M4单次同一公共测试集：A 10.385 cm、B 1.421 cm、点击offset C 1.991 cm；B+点击偏移探索为2.454 cm反而变差。预登记判定证据不足，M5最终仅用于无九点时的粗校准，不做九点微调。
- M5另次自然使用独立核对：A 12.154 cm、C 2.957 cm。不能把回放拟合成绩当独立泛化成绩。
- M9四轮硬归属80.4% / 85.3% / 76.2% / 66.7%，仅第四轮完整通过；范围Mac单用户，余量只有6.7个百分点，Windows/多人/长期稳定性未验证。
- M10 PR #17暂停、未合并；真实AI时限与质量未验收。v1.0.0、历史补tag和公开Pages已完成；[公开入口](https://shenzeyu070918-eng.github.io/monocular-gaze-mvp/)仅无摄像头星系预览和合成报告。
